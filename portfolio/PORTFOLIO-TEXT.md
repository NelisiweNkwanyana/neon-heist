# Portfolio entry: NEON HEIST

**Title:** NEON HEIST: The Blackout Protocol

**One-liner:** A third-person cyberpunk stealth-action game set in Johannesburg, 2077, playable in the browser.

**Short description (2–3 sentences):**
Pick one of four operatives, steal a hover car, break into a megacorp tower and escape with stolen files.
I built it in Godot 4 with GDScript: guard AI with vision, hearing and A* pathfinding, a combat system,
vehicle flight, a hacking minigame and an automated test that plays the whole mission.

**What I built (bullets):**
- Guard AI: 7-state machine with vision cones, hearing and A* pathfinding (AStarGrid2D)
- Combat system: 4 weapons, camera-aimed hit detection, headshots, reloads, enemy return fire
- Playable hover car with flight physics, pursuit drones and cannons
- 4 selectable characters with their own stats, perks and loadouts (data-driven)
- HUD with objectives, minimap and on-screen markers; procedural city and character animation
- Headless automated playthrough test (49 checks); exported to Web and macOS

**Tech:** Godot 4.7 · GDScript · Blender · WebAssembly · Git/GitHub
